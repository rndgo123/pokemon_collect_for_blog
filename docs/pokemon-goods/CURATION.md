# 굿즈·콜라보 글감 선별

2026-10-05. 추가 라이브러리·LLM 없이 기존 SQLite 변경 이력을 재사용한다.

```powershell
python main.py digest --days 7 --limit 10
python main.py digest --source-country KR --limit 10
python main.py digest --focus all --limit 10
```

기본은 굿즈·콜라보만 선별한다. 전체 행사·게임 후보는 `--focus all`을 사용한다.
결과에는 후보 ID·출처, 점수, 선정 이유, 기간 내 변경 항목, 추가 확인 항목을 표시한다.
이 ID를 `python main.py draft --id ID`로 전달할 수 있다.
현재 draft는 기존 사실형 텍스트이며 개인 문체·이미지 배치는 다음 단계다.

## 선정 규칙

- GOODS / COLLAB 분류 또는 제목·설명의 한국어·일본어·영어 키워드를 사용한다.
- 기간 내 신규 수집 중 최근 게시됐거나 예정·진행 중인 소식만 신규 후보로 올린다.
- 과거 공지라도 기간 내 실제 필드 변경이 있으면 후보로 올린다.
- 해시만 바뀐 이력과 오래된 공지의 최초 수입은 후보에서 제외한다.
- 종료 임박 후보를 포함하고, 이미 종료됐거나 종료일이 지난 후보는 제외한다.
- 콜라보 40 / 굿즈 30 / 기타 0 + 실제 변경 30 + 신규 20 + 종료 임박 10.
  점수는 편집 우선순위이며 검색량·조회 수·유행 점수가 아니다.
- 날짜는 한국 시간 기준이며 게시일을 판매 시작일로 추정하지 않는다.
- 동일 출처 URL에서 추적 파라미터·fragment를 제거한 뒤 동일 국가 내에서만 묶는다.
  판매국 및 소스 국가가 다르거나 상품 ID가 다르면 별도 후보로 유지한다.
- 자동 번역·제목 유사도 기반 국가 간 협업 묶기는 아직 하지 않는다.

## 추가 확인과 제한

가격·통화·판매일·국내 구매 가능 여부는 현재 모델에 구조화되어 있지 않으므로
항상 확인 과제로 표시한다. 이미지 다운로드나 새 HTTP 요청은 실행하지 않는다.
키워드 규칙은 일부 글감을 놓치거나 오탐할 수 있다. 발행할 글은 사용자가 선택한다.
공지·원문·이미지 이용 조건은 별도로 확인해야 한다.
실제 공식 RSS 활성화 여부와 선별 로직 검증은 별개다.
