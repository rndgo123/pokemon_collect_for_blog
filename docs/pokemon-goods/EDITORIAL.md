# 블로그 문체·글감 선별 기준

사용자 확정 기준. 2026-10-06 업데이트.

## 작성 전 필수 순서

1. Git에 등록된 이 문서를 먼저 읽는다. 기억이나 기본 템플릿으로 대체하지 않는다.
2. 로컬 `블로그_SEO_전략.md`를 읽고 상세 배치 기준을 적용한다.
3. 공식 판매처에서 정확한 상품·판매 상태·최초 출시일을 확인한다.
4. 확인한 사실만 개인 블로그 문체로 작성한다. 임의 발행하지 않는다.

## 문체

- 짧은 평서형 문어체: `공개했다`, `나왔다`, `구성되어 있다`, `판매될 예정이다`, `올라와 있다`.
- 한두 문장으로 소식을 바로 전하고, 한 문단에는 한 가지 정보만 담는다.
- 기존 글의 `신규 콜라보 상품을 공개했다!`, `구성되어 있고`, `판매될 예정이다`처럼 자연스러운 평서형과 줄바꿈을 사용한다. 소식 도입의 느낌표와 짧은 명사형 마무리(`가격은 5,940엔.`)는 가능하다. 임의 감상은 추가하지 않는다.
- `정리해보겠습니다`, `확인해주시기 바랍니다`, 반복적인 존댓말·보고서체를 쓰지 않는다.
- `확인하는 게 좋겠다`는 필요할 때만 쓴다. 모든 문단에 반복하지 않는다.
- 사용자에게 없는 감상·구매 의사·방문·착용·사용 경험을 만들지 않는다.
- 작업 과정 설명은 블로그 본문에 넣지 않는다. 확인되지 않은 정보는 짧게 구분한다.
- 텍스트 미리보기, MD 초안, 네이버 본문에 동일한 문체를 적용한다.
- 매번 사용자 기준 글 https://blog.naver.com/pobung2/224427577068 의 실제 문장을 확인하고 말투·문장 길이를 맞춘다. 접근할 수 없으면 이 문서의 예시를 적용하되 확인한 것처럼 말하지 않는다.
- 예시: `데덴네와 파쪼옥 굿즈가 나왔다. 일본 온라인몰에서는 10월 8일부터 판매될 예정이다.` 보고서식 표현(`공식 상품명에는 …이 적혀 있다`, `이번 공지에서 확인되지 않았다`)을 반복하지 않고 독자에게 필요한 상품·일정 정보를 바로 쓴다.

## 선별

- 콜라보는 국가와 관계없이 일반 굿즈보다 우선한다.
- 일반 상품의 국가 우선순위는 국내 → 일본 → 미국이다.
- 오늘 출시 또는 향후 **첫 출시**가 공식적으로 확인된 신상품만 선정한다. 사용자가 출시 예정만 요청하면 미래 첫 출시만 선정한다.
- 이미 판매 중·과거 출시 상품은 제외한다. 재판매·재입고·재발매·추가 물량·새 판매처 입점만으로 신규 출시로 판단하지 않는다.
- 예약 시작일, 결제 가능 여부, 배송 예정일, 기사 게시일, 지역별 판매일을 최초 출시일로 혼동하지 않는다.
- 같은 캐릭터·브랜드의 다른 상품과 혼동하지 않도록 모델명·상품명·디자인을 대조한다.
- 미래 날짜가 적혀 있어도 이미 판매 중인지 불명확하거나 출처가 충돌하면 후보에서 보류한다.
- 최근 3일 기사 요청은 게시일 조건도 함께 만족해야 한다. 조건을 임의로 완화하지 않는다.
- 기존 글과 중복되는 주제는 새 정보가 없는 한 제외한다. 맞는 후보가 없으면 없다고 알린다.
- HORI 블래키·에브이 초안은 2026-10-06 사용자 요청으로 제외했다. 9월 판매 여부는 별도 검증 없이 사실로 기록하지 않는다.

## 배치

- 관련 이미지 → 해당 설명. 이미지와 글을 각각 몰아두지 않는다.
- 모든 본문 소제목(일정·상품·출처 포함)은 네이버 **인용구 → 포스트잇** 컴포넌트로 넣는다. 현재 UI의 **인용구 5**, `quotation_postit`이다. 일반 굵은 문단이나 인용구 6(모서리)로 대체하지 않는다. 2026-10-06 사용자 수정 요청이며 이전 배치 기준보다 우선한다.
- 소제목은 포스트잇 기본 서식(19px·가운데)을 사용하고, 본문은 15px·보통·왼쪽 정렬한다. 일반 굵은 소제목보다 실제 포스트잇 컴포넌트 적용이 우선이다. 소제목 서식이 다음 설명에 상속되지 않게 한다. 표는 연한 회색 테두리(네이버 표2).
- 기간·날짜·장소·구 기준 위치는 표로 정리하되 해당하지 않는 항목은 생략한다.
- 출처 링크를 끝에 남긴다. 이미지 출처 표시와 이용 허락은 별개다.
- 기본 카테고리 포켓몬 > 이벤트. 별도 발행 요청 없으면 임시저장까지만 한다.

## 임시저장 전 검증

- 이번 글과 이후 모든 글에서 실제 소제목이 포스트잇 인용구인지 화면과 DOM의 `se-quotation` / `se-l-quotation_postit`로 확인한다. MD의 `##`만으로 네이버 인용구 적용을 완료했다고 판단하지 않는다.
- 짧은 평서형 문체, 이미지 → 설명, 본문 보통 서식, 표2, 출처 링크를 확인한 뒤 저장한다. 개인 초안·사진은 Git에 포함하지 않는다.

## 로그인

저장된 브라우저 정보로 네이버 로그인 버튼을 먼저 누른다. 실패·추가 인증·CAPTCHA일 때만 사용자에게 요청한다. 비밀번호 값을 읽거나 출력하지 않으며 인증·접근 제한을 우회하지 않는다.
