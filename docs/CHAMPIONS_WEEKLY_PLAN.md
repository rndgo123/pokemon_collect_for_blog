# 포켓몬 챔피언스 주간 사용률·실전 세팅 블로그 운영 방안

작성일: 2026-10-05 / 기준 시간: Asia/Seoul

이 문서는 글로벌 싱글배틀·더블배틀 사용률 상위 100위와 각 부문 상위 10위의 실전 세팅을 정리하는 계획이다. 사용자 확인에 따라 글로벌 통합 서버를 운영 전제로 삼고, 사용자가 제안한 OP.GG를 우선 참고한다. 실제 순위·점유율을 수집한 보고서나 발행용 초안은 아니다.

## 1. 목표와 시작 조건

목표는 매주 같은 기준으로 순위, 점유율, 전주 대비 변화를 기록하고 상위 10위 포켓몬의 기술배치·성격·노력치에 해당하는 배분·실전 역할을 설명하는 것이다.

| 목표 부문 | 전체 표 | 상세 세팅 |
|---|---:|---:|
| 글로벌 싱글배틀 | 상위 100위 | 해당 부문 상위 10위 |
| 글로벌 더블배틀 | 상위 100위 | 해당 부문 상위 10위 |

**한국·일본으로 순위를 나누지 않는다.** 한국어·일본어 페이지는 용어와 자료를 교차 확인하는 데 사용한다. 트레이너 순위에 표시된 국적도 포켓몬 사용률의 국가별 집계를 뜻하지 않는다. 글로벌 서버라는 전제와 OP.GG 통계의 실제 표본 범위는 구분하고, 원출처의 집계 대상을 확인해 본문에 적는다.

공식 명칭인 `Pokémon Champions`를 병기하고, 블로그 제목에서는 검색어로 쓰이는 ‘포켓몬 챔피언스’를 사용한다. 게임이 다른 자료나 시뮬레이터 통계를 본작 공식 랭크배틀 통계로 대체하지 않는다.

이번 계획은 사용자 요청에 따라 OP.GG를 비공식 참고 출처로 포함한다. 기존 공식 이벤트 수집기의 설정은 변경하지 않는다. 자동 수집을 추가할 때는 OP.GG의 허용된 피드·문서화된 공개 API·정책상 허용된 HTML 제공 여부를 순서대로 확인한다. 게임 내부 통신이나 비공개 API 추출을 전제로 설계하지 않는다.

새 소스는 기존 승인·비활성 게이트를 유지한다. `enabled=false`, `policy_approved=false`를 초기값으로 두고, 승인 근거를 기록한 뒤 활성화한다. 로그인·CAPTCHA·403·429를 우회하거나 실패 시 다른 접근 방식으로 자동 전환하지 않는다.

## 3. ‘주간’의 정의

가능하면 **월요일 00:00 이상~다음 월요일 00:00 미만(KST)의 실제 경기 집계**를 사용한다. 일본 시간도 UTC+9이지만 원본 시각대는 별도로 기록한다. 검토는 월요일 저녁을 기본 운영안으로 하되 데이터 갱신이 늦으면 다음 갱신 후 작성한다. 자동 일정은 등록하지 않는다.

실제 주간 경기 집계가 없으면 매주 같은 요일·시각의 공식 누적 통계를 저장해 전주 스냅샷과 비교한다. 이때 제목은 ‘주간 사용률’ 대신 **‘주간 사용 순위 변화 — 시즌 누적 통계 기준’**으로 쓴다. 누적 비율의 차이가 그 주에 진행된 경기의 사용률은 아니다. 충분한 원시 건수와 동일한 집계 정의가 없으면 주간 비율을 역산하지 않는다.

각 회차에는 실제 관측 시각, 원본 갱신 시각, 실제 집계 기간을 구분해 적는다. 첫 회차는 비교 자료가 없으므로 등락을 `비교 없음`으로 표시한다.

## 4. 상위 100위 표와 계산 규칙

부문별로 다음 표를 만들고, 모바일에서는 1~25위·26~50위·51~75위·76~100위로 나눈다. 아래 행은 입력 형식이며 실제 통계가 아니다.

| 이번 순위 | 포켓몬·폼 | 점유율(사용률) | 전주 순위 | 순위 등락 | 점유율 변화 |
|---:|---|---:|---:|---|---:|
| {순위} | {한국어 이름·폼} | {값 또는 미공개} | {값 또는 확인 불가} | {▲N / ▼N / — / 진입 / 비교 없음} | {±N.N%p 또는 비교 불가} |

- **점유율**: 원출처의 정의와 분모를 그대로 명시한다. 팀 채용률, 실제 선출률, 전체 슬롯 비중을 섞지 않는다. 팀 채용률은 여러 포켓몬이 한 팀에 함께 들어가므로 합계가 100%가 아닐 수 있다.
- **순위 등락**: `전주 순위 − 이번 순위`. 전주 12위 → 이번 8위는 `▲4`다. 동률은 원출처 순위를 유지한다.
- **OP.GG 화면 등락**: 현재 확인한 랭킹 화면은 이전 시즌 대비다. 블로그의 전주 등락과 섞지 않는다. 세부 항목의 변화도 비교 기준이 확인되지 않으면 전주 변화로 사용하지 않는다.
- **점유율 변화**: `이번 점유율 − 전주 점유율`. 18.2% → 20.1%는 `+1.9%p`다. 증가율 %와 구분하고 계산 후 표시 자리에서 반올림한다.
- **상위 100위 진입**: 전주 상위 100위 밖임이 확인되면 `진입`으로 표시한다. 정확한 전주 순위가 없으면 101위로 가정하거나 등락 폭을 만들지 않는다.
- **자료 누락**: 전주 자료 자체가 없으면 `비교 없음` 또는 `확인 불가`다. 신규 포켓몬이라고 단정하지 않는다.
- **이탈**: 전주 상위 100위였으나 이번에는 밖인 포켓몬을 별도 짧은 표로 적는다. 이번 전체 순위가 없으면 `100위 밖`으로만 표시한다.
- **언어별 페이지**: 한국어·일본어 페이지의 갱신 시각 차이를 국가별 인기 차이로 해석하지 않는다.
- **비율 미제공**: 순위만 공개되면 점유율은 `미공개`다. 도구·특성 채용률을 포켓몬 자체의 사용률 칸에 넣지 않는다.
- **시즌·규칙 변경**: 같은 조건의 자료가 없으면 `시즌 변경으로 비교 제외`로 표시한다. 분모·표본이 달라졌을 때도 직접 비교를 중단한다.
- **100종 미만 제공**: 확보된 범위까지만 게재하고 ‘상위 100위’ 대신 실제 범위를 제목에 쓴다.

포켓몬 이름은 종뿐 아니라 폼·성별 구분이 통계에서 어떻게 처리되는지 확인해 맞춘다. 한국어·일본어 표시명을 별도로 보관하고 동일 포켓몬 식별자로 연결한다. 메가진화 전후 통계를 임의로 합치거나 나누지 않는다.

## 5. 각 부문 상위 10위 상세 세팅

‘실전타입’은 우선 **실전 역할**로 해석한다. 물리 공격형·특수 공격형·양쪽 공격형·물리 막이·특수 막이·서포터·트릭룸·날씨 전개 등이다. 포켓몬의 속성 타입 및 테라스탈 같은 배틀 기믹과는 구분한다. 사용자가 속성이나 다른 의미를 원하면 항목명을 바꾼다.

‘성격’은 본작에서 표시하는 능력 보정과 연결해 기록한다. ‘노력치’는 독자에게 익숙한 검색어로 병기하되, 실제 입력값은 **챔피언스에서 사용하는 능력 배분 단위**로 적는다. 이전 작품의 `252/252/4`를 그대로 복사하거나 근거 없이 환산하지 않는다. 배분 상한과 합계 제한은 해당 버전에서 확인한다.

### 상위 10위 공통 카드

| 항목 | 작성 내용 |
|---|---|
| 포켓몬·폼 / 현재 순위 | 해당 부문 기준 이름·폼과 순위 |
| 점유율 / 전주 대비 | 전체 표와 같은 수치·기준 |
| 실전타입(역할) | 주 역할 1개, 필요하면 보조 역할 1개 |
| 기술배치 | 함께 사용되는 4기술이 확인되면 그 조합. 개별 채용률만 있으면 인기 기술 목록으로 표시 |
| 성격 / 능력 보정 | 이름이 확인되면 한국어 이름 병기. 상승·하락 능력도 함께 기재 |
| 노력치에 해당하는 능력 배분 | HP / 공격 / 방어 / 특수공격 / 특수방어 / 스피드 순서, 단위 명시 |
| 특성 / 지닌 도구 | 해당 세팅의 특성과 도구. 변신 전후 구분이 필요하면 표시 |
| 사용 목적 | 선봉·마무리·속도 제어 등 실제 운용과 배분 근거를 짧게 설명 |
| 주의점 | 팀 의존성·주요 약점·규칙 제한 중 중요한 내용만 기재 |
| 근거 | 출처 링크·시즌·규칙·확인일 / 통계 또는 편집 추천 구분 |

**통계와 추천 세팅을 구분한다.** 기술·성격·도구 각각의 최빈값이 하나의 팀에서 함께 쓰였다는 뜻은 아니다. 인기 기술 4개를 묶어 ‘가장 많이 쓰는 기술배치’라고 쓰지 않는다. 공동 조합 데이터가 없다면 ‘개별 기술 채용률’과 ‘편집 추천 조합’을 나눈다.

능력 배분 분포가 미공개면 `통계 미공개`로 두고, 필요할 때만 같은 규칙의 공개 대회 팀 또는 직접 검증한 세팅을 ‘참고 세팅’으로 추가한다. 대회 공개 팀에 배분이 없으면 추정하지 않는다. 속도·내구 조정의 의미를 설명하려면 레벨·상대 세팅·필드 조건을 확인한다. 확인하지 않은 ‘확정 1타’, ‘무조건 선공’, ‘최적 세팅’ 표현은 쓰지 않는다.

싱글과 더블에서 같은 포켓몬이 상위권이어도 세팅을 자동 복제하지 않는다. 더블의 보호·속도 제어·파트너 의존성 등을 별도로 검토한다. 여러 부문에 중복되는 포켓몬의 이름·기본 정보는 재사용하되 부문별 근거와 세팅을 유지한다.

## 6. 게시물 구성과 SEO 적용

**글로벌 싱글 글 1개, 글로벌 더블 글 1개**를 기본으로 한다. 각 글에 TOP 100과 해당 부문 TOP 10 세팅을 함께 넣는다. 한국·일본별로 같은 통계를 복제하지 않는다.

제목 예시:

- `포켓몬 챔피언스 싱글배틀 사용률 TOP 100 — {기간} 글로벌 순위와 상위 10위 세팅`
- `포켓몬 챔피언스 더블배틀 사용률 TOP 100 — {기간} 글로벌 점유율·등락`
- 주간 집계·점유율 미확보 시: `포켓몬 챔피언스 싱글배틀 주간 순위 변화 — {확인일} OP.GG 시즌 통계 기준`

본문 순서는 다음과 같다.

1. 도입 1~2문장과 기준 요약: 집계 기간·시즌·규칙·대상·출처.
2. 대표 이미지가 확보되면 이미지 다음에 해당 설명을 배치한다.
3. 이번 회차의 주요 변화 3가지: 수치로 확인된 상승·하락·진입.
4. 글로벌 TOP 100 → 해당 부문 TOP 10 세팅.
5. 필요하면 싱글·더블 양쪽 상위권에 든 포켓몬의 역할 차이를 설명한다.
6. 출처 링크·확인 시각·비교 한계와 이전 회차 링크.

짧은 평서형 문체를 사용하고 실제 플레이하지 않은 경험은 만들지 않는다. 개별 포켓몬 10마리 설명과 100위 표가 필요한 글이므로 일반 상품 글의 글자 수·사진 수 목표를 강제로 적용하지 않는다. 순위와 점유율은 검색 가능한 텍스트 표로 남긴다. 이미지는 직접 캡처 또는 사용 가능 여부가 확인된 것만 사용한다.

글로벌 기준·기간·배틀 형식을 제목과 첫 표에 명확히 적는다. 정해진 횟수만큼 키워드를 반복하지 않는다. ‘사용률 순위’를 ‘강함의 티어표’나 ‘승률 순위’로 바꾸지 않는다. 발행 후 7일·28일 검색 유입을 확인하고 실제 질문에 맞춰 설명을 보완한다. 세부 문체·서식 기준은 로컬 `블로그_SEO_전략.md`를 따른다.

## 7. 최소 운영 흐름

처음에는 별도 대시보드나 자동 발행 시스템을 만들지 않는다. 허용된 자료를 수동으로 확인하고 부문별 표와 상위 10위 카드로 1회차를 작성한다. 원본 수치와 집계 조건을 기록한 뒤 두 번째 회차부터 같은 조건끼리 비교한다.

향후 파일 입력으로 관리할 경우 최소 필드는 다음과 같다. 아직 파일·코드로 구현하지 않는다.

| 묶음 | 기록할 필드 |
|---|---|
| 집계 기준 | 출처 URL, 집계 대상 국가 또는 글로벌, 싱글/더블, 시즌, 레귤레이션, 랭크 구간, 플랫폼 범위 |
| 시각·정의 | 기간 시작·끝, 원본 시각대, 원본 갱신 시각, 관측 시각, 주간/누적 구분, 분모 정의·표본 수(공개 시) |
| 순위 | 포켓몬 식별자·폼, 한국어·일본어 이름, 원본 순위, 원본 사용률·정밀도, 전주 비교 가능 여부 |
| 상위 10위 | 기술 조합/개별 채용률 구분, 성격·보정, 배분값·단위, 특성·도구, 역할, 통계/참고/편집 추천 구분, 근거 URL |

데이터 확보와 정책 검토가 끝나고 수동 운영의 반복 부담이 확인된 경우에만 기존 Python 표준 라이브러리와 저장 방식을 재사용해 입력·비교·Markdown 출력부터 추가한다. 이벤트 수집기의 국가 필드는 출처 국가를 뜻하므로 플레이어 집계 국가 필드로 재사용하지 않는다. 원시 통계·캡처·주간 보고서는 기존 Git 제외 원칙을 유지하고 프로젝트 계획·템플릿·코드만 버전 관리한다.

## 8. 발행 전 검증과 첫 회차 완료 기준

- [ ] 글로벌 기준을 표시했고, OP.GG의 실제 집계 대상과 트레이너 국적을 혼동하지 않았다.
- [ ] 실제 주간 집계와 누적 스냅샷 비교를 구분하고 기간·시각·규칙을 표시했다.
- [ ] 각 부문의 제공 범위를 확인했고, 100위까지 없으면 실제 범위로 수정했다.
- [ ] 포켓몬·폼 식별과 원출처 동률 처리에 맞게 순위를 옮겼다.
- [ ] 순위·비율·채용률의 의미와 분모를 확인했다. 미공개 항목을 추정하지 않았다.
- [ ] `12위 → 8위 = ▲4`, `18.2% → 20.1% = +1.9%p`처럼 등락 방향·단위를 확인했다.
- [ ] 이전 순위가 없거나 시즌·규칙이 바뀌면 임의의 등락을 넣지 않았다.
- [ ] 각 부문 상위 10위 카드에 요청한 4개 항목이 있고, 없는 통계는 미공개로 표시했다.
- [ ] 개별 최빈값과 실제 함께 쓰이는 세팅을 구분했다. 능력 배분 단위·상한을 확인했다.
- [ ] 사용·재게시 가능한 출처와 이미지만 사용했고 링크·확인일을 남겼다.
- [ ] 블로그 초안을 검토했다. 별도 발행 요청 전에는 초안으로 보관한다.

첫 회차는 검증된 범위의 싱글·더블 순위표와 각 TOP 10 카드가 갖춰지면 완료다. 점유율·능력 배분 자료가 확보되지 않은 부분은 누락 사유를 명시한다. 전체 목표를 달성한 것처럼 표시하지 않는다.
